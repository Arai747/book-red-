BOOKREC — АЛҒАШҚЫ ДИЗАЙН ЖӘНЕ 270 КІТАПТЫҢ СИПАТТАМАСЫ

1. Осы сыртқы архивті БІР РЕТ ашыңыз.
2. GitHub-тағы жаңа сайтыңыздың негізгі бумасына осы үш файлды жүктеңіз:
   app.py
   requirements.txt
   bookrec_bundle.zip
3. bookrec_bundle.zip архивін АШПАҢЫЗ. Сайт оның ішіндегі бумаларды өзі қалпына келтіреді.
4. app.py файлын жаңасымен ауыстырыңыз. Үш файл бір жерде тұруы керек.
5. Streamlit → Manage app → Reboot app басыңыз. Main file path: app.py.

Бұрынғы тегістеліп жүктелген суреттер мен Python файлдары жаңа нұсқаға кедергі келтірмейді; олар қолданылмайды.

Кітаптар бетінде барлық 270 кітаптың қысқаша сипаттамасы көрсетіледі. Толығырақ батырмасы толық сипаттаманы ашады. Басты бет ең алғаш жасалған BookRec дизайнын сақтайды.

Python және SQLite/ML бастапқы коды bookrec_bundle.zip ішіндегі backend бумасында. Дизайн frontend ішінде. Оқу үшін ішкі архивтің көшірмесін бөлек ашуға болады; GitHub-қа салынатын bookrec_bundle.zip-ті өзгертпеңіз.
